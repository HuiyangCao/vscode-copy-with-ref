# 平铺命令配置设计

## 目标

将每个工程的命令配置简化为 YAML 根数组。每个数组元素只包含命令名 `name` 和命令内容 `command`，命令管理器直接平铺显示这些命令。

## 配置格式

```yaml
- name: NVIDIA SMI
  command: nvidia-smi

- name: 本地到 f3
  command: |
    rsync -av --delete \
      --exclude='build/' \
      /home/chy/tiji_ws/ \
      f3:/home/user/tiji_ws/
```

配置文件必须满足以下约束：

- YAML 根节点必须是数组。
- 每项必须提供非空字符串 `name`。
- 每项必须提供非空字符串 `command`。
- 不支持旧的 `commands`、`groups`、`parameters` 结构，也不执行自动迁移。

## 代码结构与数据流

`CommandManagerProvider` 读取当前工程对应的 YAML 文件，将根数组中的每项转换为一个叶子命令节点。根节点直接返回全部命令，不再创建或展开分组节点。

用户点击命令后，扩展直接去除 YAML 块标量产生的末尾空白，将命令发送到当前终端；如果没有终端，则创建一个以命令名命名的终端。不再扫描花括号、不再弹出参数输入框，也不再保存参数状态。

单条命令编辑功能继续按 `name` 定位 YAML 中对应条目。工程级新建、编辑、删除配置及文件监听行为保持不变。

## 错误处理

- YAML 语法错误沿用现有错误提示。
- YAML 根节点不是数组时，显示配置格式错误，树中不显示可执行命令。
- 数组项缺少有效 `name` 或 `command` 时，显示配置格式错误，避免执行空命令或展示模糊占位名称。
- 空数组显示“配置为空，点击编辑”的现有占位入口。

## 测试

- 根数组中的单行与多行命令可被解析并保持顺序。
- 空数组返回空命令列表。
- 非数组根节点被拒绝。
- 缺少或使用空 `name`、`command` 的条目被拒绝。
- 命令执行只裁剪末尾空白，不再替换花括号内容。
- TypeScript 编译通过。
